01 — Glossário

TERMO — Conceitos Fundamentais

Antes de escrever qualquer linha de código, é essencial conhecer o vocabulário do React. Esses são os termos que aparecem em todo projeto React — dominar o significado de cada um torna o aprendizado muito mais rápido.

Componente

Component

Função JavaScript que retorna JSX (HTML dentro do JS). É o bloco fundamental do React. Cada parte da tela é um componente.

Props

Properties

Dados passados do componente pai para o filho. Funcionam como parâmetros de função — somente leitura para quem recebe.

State

Estado

Memória interna de um componente. Quando o estado muda, o React re-renderiza o componente automaticamente.

Hook

useState / useEffect

Funções especiais do React que permitem usar estado e outros recursos dentro de componentes funcionais.

JSX

JavaScript + XML

Sintaxe que permite escrever HTML dentro do JavaScript. O React transforma isso em chamadas de função.

📌 Regra de Ouro No React, dados sempre fluem de cima para baixo (pai → filho via props). Para que um filho se comunique com o pai, o pai deve passar uma função como prop para o filho chamar.
02 — Motivação

CONTEXTO — O que estamos construindo?

O Jogo da Velha (Tic-Tac-Toe) é o projeto tutorial oficial do React. Parece simples, mas ele cobre todos os conceitos essenciais do framework de uma só vez.

O que aprenderemos

Componentes

Square, Board e Game — três componentes com responsabilidades distintas.

O que aprenderemos

Estado compartilhado

Levantar estado ao componente pai para que filhos possam se comunicar.

O que aprenderemos

Imutabilidade

Por que nunca mutamos o estado diretamente — e como criar novas cópias.

O que aprenderemos

Histórico de Jogadas

Armazenar cada estado do tabuleiro para permitir "viagem no tempo".

⚙ Pré-Requisitos Você precisa conhecer funções JavaScript, arrays, desestruturação e o básico de HTML/CSS. Não é necessário conhecer React previamente — é exatamente para isso que esse tutorial existe!

O projeto final terá: um tabuleiro 3×3 clicável, alternância entre jogadores X e O, detecção automática de vencedor e botões para revisitar qualquer jogada anterior.

03 — Arquitetura

CONEXO — Como os Conceitos se Conectam

Antes de codificar, entenda a hierarquia de componentes e como os dados fluem entre eles. Esse diagrama mental é o coração do React.

Hierarquia de Componentes
Game
↓ passes: squares[], onPlay()
Board
↓ passes: value, onSquareClick()
Square
Square
Square
... × 9
↑ eventos sobem via callbacks
Game (pai)

Dono do Estado

Guarda o histórico de todos os tabuleiros e qual jogada está sendo exibida. É aqui que vive o useState.

Board (filho)

Renderizador

Recebe o array de 9 casas via props e renderiza os 9 Squares. Não tem estado próprio.

Square (neto)

Unidade Atômica

Um botão que exibe "X", "O" ou vazio. Quando clicado, chama a função que o pai passou — ele mesmo não altera o estado.

💡 Por que levantar o estado? Se cada Square guardasse seu próprio estado, o Board não conseguiria verificar quem ganhou — precisaria "pedir" para cada filho. É mais simples e previsível ter o estado em um único lugar (Game) e distribuir via props.

O conceito de imutabilidade também é fundamental: em vez de alterar o array do tabuleiro, criamos uma cópia com .slice(), modificamos a cópia e salvamos a nova versão. Isso torna possível o histórico de jogadas.

// ❌ Nunca faça isso (mutação direta) squares[i] = 'X'; // ✅ Faça isso (nova cópia imutável) const nextSquares = squares.slice(); nextSquares[i] = 'X'; setSquares(nextSquares);
04 — Implementação

DIALED — Construindo Passo a Passo

Agora vamos ao código. Cada passo adiciona uma camada de funcionalidade ao jogo. Siga a sequência — cada etapa depende da anterior.

Componente Square — O botão

Começa pelo menor elemento: um botão que recebe seu valor via props e notifica o pai quando clicado.

function Square({ value, onSquareClick }) { return ( <button className="square" onClick={onSquareClick}> {value} </button> ); }
🔍 Note Square não sabe nada sobre o jogo — só exibe o que recebe. Toda lógica fica nos componentes superiores.

Componente Board — O tabuleiro

Renderiza os 9 Squares e gerencia cliques. Recebe o array squares e a função onPlay do Game.

function Board({ xIsNext, squares, onPlay }) { function handleClick(i) { // Ignora se já existe valor ou há vencedor if (squares[i] || calculateWinner(squares)) return; const nextSquares = squares.slice(); nextSquares[i] = xIsNext ? 'X' : 'O'; onPlay(nextSquares); } const winner = calculateWinner(squares); const status = winner ? `Vencedor: ${winner}` : `Próximo: ${xIsNext ? 'X' : 'O'}`; return ( <> <div className="status">{status}</div> {[0,3,6].map(row => ( <div className="board-row"> {[0,1,2].map(col => ( <Square value={squares[row + col]} onSquareClick={() => handleClick(row + col)} /> ))} </div> ))} </> ); }

Componente Game — O controlador

Aqui fica todo o estado do jogo. Armazena o histórico de tabuleiros e a jogada atual.

export default function Game() { const [history, setHistory] = useState([Array(9).fill(null)]); const [currentMove, setCurrentMove] = useState(0); const xIsNext = currentMove % 2 === 0; const currentSquares = history[currentMove]; function handlePlay(nextSquares) { const nextHistory = [...history.slice(0, currentMove + 1), nextSquares]; setHistory(nextHistory); setCurrentMove(nextHistory.length - 1); } function jumpTo(move) { setCurrentMove(move); } const moves = history.map((_, move) => ( <li key={move}> <button onClick={() => jumpTo(move)}> {move ? `Ir para jogada #${move}` : 'Ir para o início'} </button> </li> )); return ( <div className="game"> <Board xIsNext={xIsNext} squares={currentSquares} onPlay={handlePlay} /> <ol>{moves}</ol> </div> ); }

Função calculateWinner — A lógica de vitória

Verifica as 8 combinações possíveis de vitória no tabuleiro 3×3.

function calculateWinner(squares) { const lines = [ [0,1,2], [3,4,5], [6,7,8], // linhas [0,3,6], [1,4,7], [2,5,8], // colunas [0,4,8], [2,4,6], // diagonais ]; for (const [a, b, c] of lines) { if (squares[a] && squares[a] === squares[b] && squares[a] === squares[c]) return squares[a]; } return null; }
